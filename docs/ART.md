# 아트 디렉션

**레퍼런스 코드: `design/style-preview.html`** — 브라우저로 열면 움직이는 장면이 나온다. 고양이·뚝배기·화구·테이블·말풍선을 만드는 함수(`makeCat`, `makeBowl`, `rbox`, `smoothNormals`, `drawDish`, `bubble`, `gauge`)를 TypeScript 모듈로 옮겨 그대로 출발점으로 쓴다. 레퍼런스보다 못생겨지면 안 된다.

### 레퍼런스를 최신 three로 옮길 때 주의
레퍼런스는 CDN의 three r128로 작성됐다. npm 최신 three로 옮기면:
- `THREE.LuminanceFormat` → `THREE.RedFormat` (그라디언트 맵 DataTexture)
- 캔버스 텍스처에 `texture.colorSpace = THREE.SRGBColorSpace`
- 최신 버전은 색 관리가 기본으로 켜져 있어 같은 hex라도 밝기가 달라질 수 있다. 레퍼런스 스크린샷(`docs/shots/00-reference.png`)과 나란히 놓고 조명 세기를 조정해 같은 인상으로 맞춘다.
- 외곽선 ShaderMaterial, `LatheGeometry`, `ExtrudeGeometry` 사용법은 그대로 동작한다.

## 1. 느낌
- 통통하고 둥근 고양이, 굵은 잉크 외곽선, 파스텔 바닥, 3단 툰 셰이딩. 2D 모바일 타이쿤 일러스트를 3D로 옮긴 느낌.
- 사실적인 조명·질감·그림자 금지. 대신 반투명 원형 그림자(blob).
- 정신없이 바쁜 게임이므로 **신호는 크고 단순하게**: 말풍선, 게이지, 완료 알림, 동전은 3D 물체보다 항상 위에 그린다.

## 2. 렌더링
| 항목 | 값 |
|---|---|
| 카메라 | `OrthographicCamera`, 피치 46°, 요 10° (오른쪽 앞에서 내려다봄) |
| 화면 맞춤 | 가게 경계 박스 8점을 카메라 공간으로 투영해 맞춤. 상단 HUD 19%, 하단 10% 여백. 좌우는 최대 4% 잘림 허용 |
| 재질 | `MeshToonMaterial` + 3단 그라디언트(95/175/255), 같은 색은 재질 공유 |
| 조명 | Ambient 0.52 + Directional 0.56 (왼쪽 위 앞) |
| 외곽선 | 뒷면 렌더 복제 메쉬, 법선 방향으로 0.02~0.04 부풀림. 각진 형상은 위치가 같은 정점의 법선을 평균 낸 사본 사용(`smoothNormals`) |
| 그림자 | 그림자 맵 끔. 원형 blob(검정 14% 불투명) |
| 픽셀 비율 | `min(devicePixelRatio, 2)` |
| 성능 | 갤럭시 S25급 60fps, 보급형 30fps 이상. 드로우콜 300 이하 목표 |

## 4. 고양이
- 몸통과 머리가 하나인 콩 모양: 반지름 0.42 구, 스케일 (1, 1.08, 0.94). 키 약 0.9칸.
- 얼굴: 검은 구 눈 + 흰 하이라이트, 분홍 볼터치, 흰 주둥이, 분홍 코, "ω" 입(반원 토러스 2개).
- 귀: 원뿔 2개(안쪽 분홍), 꼬리: 등을 따라 위로 말린 튜브(`TAIL_CURVE`). 몸 뒤로 0.62칸 넘게 나가지 않는다.
- 털 무늬 6종(캔버스 텍스처): 치즈(줄무늬), 고등어(줄무늬, 흰 배 없음), 삼색, 턱시도, 크림, 검정.
- **손님** = 목도리(랜덤 색 8종). **귀빈** = 선글라스 + 금색 목도리. **관광객** = 작은 배낭.
- **주방장** = 흰 셰프 모자 + 흰 앞치마. **서버** = 남색 앞치마 + 주황 두건 + **머리 위로 든 쟁반**(두 앞발을 올림). **설거지 알바** = 분홍 두건 + 노란 고무장갑.
- 등급 소품: 베테랑 은색 배지, 장인 금색 배지(가슴).

### 애니메이션 (모두 코드 트윈, 뼈대 없음)
| 상태 | 동작 |
|---|---|
| 대기 | 숨쉬기(몸 Y 스케일 ±2.2%), 꼬리 흔들기 |
| 걷기 | 몸 통통 튀기(|sin|×0.07, 빠른 주기), 진행 방향으로 0.1초 안에 회전 |
| 손 들기 | 오른앞발이 머리 옆에서 흔들림 |
| 발 구르기 | 앞발 빠르게 위아래 + 몸 좌우 미세 흔들림 + "탁탁" 효과선 |
| 식사 | 몸을 앞으로 0~0.1 rad 까딱(`EAT_LEAN`), "냠" 글자 깜빡, 국물 김. 그 이상 기울이지 않는다 |
| 화남·퇴장 | 몸 빨갛게 한 번 깜빡, 귀 뒤로, 빠른 걸음으로 퇴장, 머리 위 "흥!" |
| 행복 퇴장 | 하트 1개 떠오름 |
| 등장·퇴장 순간 | 흰 연기 뿅 |

## 5. 소품
- 뚝배기: Lathe 단면(레퍼런스 `bowlProfile`). 순대 조각(진보라 원통) + 파(초록 조각), 얼큰은 빨간 국물 + 고춧가루. 수육은 흰 접시 + 분홍 고기 4조각.
- 화구: 어두운 둥근 판 + 링 + 불꽃 원뿔 8개(조리 중에만), 위에 뚝배기가 직접 올라가 끓는다(국물 표면 기포).
- 배식대: 원목 카운터, 국밥이 올라갈 칸 위치가 정해져 있다.
- 개수대: 하늘색 캐비닛 + 수도꼭지. 더러운 그릇이 쌓인 높이로 찬 정도가 보인다. 꽉 차면 빨간 "FULL" 말풍선.
- 그릇 더미: 화구 옆, 남은 개수 숫자 칩.
- 벽: 간판(가게 이름), 메뉴판(해금 메뉴는 가격, 잠긴 메뉴는 "준비중"), 창문, 화분. 티어별 장식(동네 맛집 화분 추가, 블루리본 리본 간판, 미슐랭 별 3개 현판).
- 입구: 남색 노렌 "국밥". 바깥 보도에 웨이팅 줄과 차단봉.

## 6. 2D UI 위 3D 신호 (캔버스 스프라이트, `depthTest:false`)
- 주문 말풍선: 흰 둥근 사각 + 꼬리 + 메뉴 아이콘 + 인내심 게이지(초록 >50% / 노랑 >20% / 빨강).
- 화구 링: 조리 중 흰 원 + 초록 진행 링 + 메뉴 아이콘. 완료 시 노란 원 "완료!" + 빨간 카운트다운 링, 통통 튐.
- 동전: 노란 ₩ 동전이 테이블 위에서 튐. 개수대가 꽉 차서 못 치우면 회색.
- 숫자 팝업: "+9,000원"(노랑), "서빙 완료"(초록), 리뷰 점수. 잉크 외곽 글자.
- 글꼴: Jua(Google Fonts) — 게임 UI 전부. 로딩 전엔 시스템 고딕으로 대체하되 스프라이트는 폰트 로드 후 다시 그린다.

## 7. HUD (HTML/CSS 오버레이)
- 흰 알약 + 2.5px 잉크 테두리 + 아래로 3px 잉크 그림자(만화풍 버튼). 숫자는 tabular-nums.
- 정비 화면 카드도 같은 언어. 둥글고 두꺼운 테두리, 누르면 2px 내려가는 피드백.
- 세이프 에어리어: `env(safe-area-inset-*)` 반영.

## 8. 겹침 방지 (캐릭터는 아무것도 뚫지 않는다)
레퍼런스의 수치는 실제 관통 검사로 확인한 값이다(`?debug=overlap`, 32초 애니메이션 동안 관통 0).

### 8.1 고양이 크기 기준
| 부위 | 범위 |
|---|---|
| 몸통 | 폭 0.84, 앞쪽 0.43(앞발 포함), 키 0.95 |
| 꼬리 | 몸 중심에서 뒤로 0.62, 높이 0.65까지 |
| 쟁반(서버) | 머리 위 높이 1.1, 반경 0.24 |
| 셰프 모자 | 높이 1.3까지 |

### 8.2 배치 규칙 (레이아웃 데이터에서 계산으로 강제)
- **의자 중심 = 테이블 가장자리에서 0.5칸 바깥**(`SEAT_GAP`). 좌석 방향은 테이블 중심을 본다.
- 나란히 앉는 좌석 간격 ≥ 0.9. 4인석 테이블 폭 1.7 × 깊이 1.0, 2인석 1.0 × 0.9. 6인석·8인석도 같은 규칙으로 좌석을 계산한다.
- 국밥 그릇 위치 = 그 좌석 쪽 테이블 가장자리에서 0.2칸 안쪽.
- 사람(고양이)이 다니는 통로 폭 ≥ 1.1칸(몸 앞 0.43 + 꼬리 0.62). 주방 조리대와 배식대 사이도 같다.
- 웨이팅 줄 간격 1.1칸, 차단봉에서 0.5칸.
- 주방장은 조리대 앞면에서 0.47칸 떨어져 선다.

### 8.3 이동 규칙
- 바닥 그리드(0.5칸)에서 테이블·의자·카운터·벽 칸은 막힘, 그 주변 0.45칸도 막힘으로 팽창시킨 뒤 A* 경로.
- 움직이는 고양이끼리는 반경 0.45 분리 조향으로 서로 비켜 간다. 앉아 있는 고양이는 밀리지 않는다.
- 서빙·주문·치우기 때 서버는 테이블 끝(좌석이 없는 쪽) 정해진 서비스 지점에 선다. 쟁반은 머리 위라 테이블 위로 겹쳐도 높이가 다르다.

### 8.4 애니메이션 규칙
- 모든 동작은 위 크기 기준 안에서만 움직인다. 식사 기울기 최대 0.1 rad, 손 들기·발 구르기는 몸 옆·앞 0.1칸 안.
- 앉기·일어나기는 의자 위치에서 위아래로만 움직이고, 테이블 쪽으로 미끄러지지 않는다.

### 8.5 자동 검사 (필수)
- 개발 모드에서 `?debug=overlap` 이면 매 프레임 고양이(몸 구 0.40, 앞발 구 0.1, 꼬리 표본점, 쟁반)와 고정 물체 AABB, 고양이끼리를 검사해 관통 깊이를 기록한다(자기가 앉은 의자는 제외).
- e2e 테스트: 직원 풀세트·10테이블 상태로 1일 영업을 돌리고 **관통 0.02칸 초과 0건**을 확인한다.
- 레퍼런스의 `overlapNow`, `overlapReport` 를 그대로 옮겨 쓴다.
